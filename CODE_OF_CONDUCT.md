# Code of Conduct

We want this project to be a friendly and respectful place for everyone, whatever their experience, background or language.

**Please**
- Be kind and patient, especially with people who are new to the project.
- Give and accept feedback about the work, not the person.
- Assume good intent and ask when something is unclear.

**Please do not**
- Insult, harass or discriminate against anyone.
- Publish other people's private information.
- Post spam or off-topic promotion.

Maintainers may edit or remove comments, issues and contributions that break these rules, and may block repeat offenders.

To report a problem, contact the maintainer through [@ChornChhery](https://github.com/ChornChhery) on GitHub (or use a private security advisory for sensitive reports).
